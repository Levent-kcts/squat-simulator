# Claude hafıza kopyası

Bu klasör, Claude Code'un bu proje için tuttuğu kalıcı hafızanın (kullanıcı tercihleri, sahibin kararları, devam eden işler) bir KOPYASIDIR.
Amaç: graphify bilgi grafiğine "şimdiye kadar yapılan her şeyi" (kod + belgeler + kararlar) dahil etmek.
Asıl hafıza `%USERPROFILE%/.claude/projects/<proje>/memory/` altındadır; bu kopya `graphify` grafiği yenilenirken güncellenir.
